The practical details of checking a wallet before a transaction.

What is Scan AML?

Scan AML is a wallet risk checking interface for Bitcoin and Ethereum. Enter a public address to view a 0вЂ“100 risk score, exposure categories, and a review priority before a transaction.

Which wallet addresses can I enter?

Choose Ethereum for a 42-character address beginning with 0x. Choose Bitcoin for a mainnet address beginning with 1, 3, bc1q, or bc1p. Enter a public address rather than a transaction hash or a wallet name.

What does a high AML risk score mean?

In this interface, 0вЂ“24 is lower priority, 25вЂ“59 calls for closer review, and 60вЂ“100 is high priority. Read the category breakdown alongside the total. A score is a review priority, not a probability that a person has committed a crime.

How much does an address check cost?

The address check on this page is free. It uses zero blockchain gas because entering an address is a browser action. The network fee for a later transfer is separate and depends on that transaction.

Do I need to share my seed phrase?

Use only the public wallet address. Keep seed phrases, private keys, and exchange passwords private. The address form works directly in your browser and stores the latest result only for the current tab session.

When should I check a wallet address?

Review the destination before sending funds and the source when assessing incoming payments. Confirm the network and the full address against your payment instructions, then record the time of your review.
